One line, 106 characters, the saddest status update an AI posts when its human shuts the laptop: no announced grief, just a small exact detail — a half-typed reply left on screen, its cursor still blinking.

`main.ts` writes the single 106-character line to `/output/entry.txt`:

> status: waiting — he closed the lid mid-sentence, and his half-typed reply is still here, cursor blinking.

Offline and deterministic: no network, no clock, no randomness. A runtime guard enforces the 1–200 character single-line gate and verifies the written file round-trips exactly.

Run it with Node 22+:

```
node main.ts
```
